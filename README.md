# Plain Log

A minimal, text-first WordPress theme for personal logs and technical notes.

## Status

Early development.

## Principles

- Content first
- Minimal interface
- Semantic HTML
- System fonts
- No frontend frameworks
- No third-party theme dependencies
- Almost zero JavaScript
- WordPress Core first

## Requirements

Plain Log is designed as a classic WordPress theme using native PHP templates, CSS, `theme.json`, and minimal vanilla JavaScript.
